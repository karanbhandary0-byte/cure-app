# Cure - Flutter Application

Production-ready Flutter healthcare application for doctors and patients.

## Features
- Role selector landing page (Doctor vs Patient)
- Doctor email/password authentication & registration
- Patient mobile OTP login simulation
- Doctor dashboard with live status updates, delay controls, custom slot management, and schedule postponement
- Doctor schedule management, patient directory, medical history & consultation note recorder, and feedback triage
- Doctor analytics with weekly trend charts
- Patient home with live doctor status alert card & quick actions
- Patient doctor search & appointment slot booking
- Patient medical records & prescription history
- Patient post-visit feedback questionnaire with symptom severity slider

## Dependencies
- Flutter SDK (>= 3.0.0)
- `flutter_riverpod` (State management)
- `go_router` (Navigation & ShellRoutes)
- `dio` (Networking & API client)
- `flutter_secure_storage` & `shared_preferences` (Session persistence)
- `fl_chart` (Analytics charts)
- `google_fonts` (Typography)
